Engine Architecture

Built for High-Fidelity Agent Memory

Traditional context windows lose critical decisions during long coding runs. OpenAtlas provides deterministic, structural memory.

Native SQLite & Vector Hybrid

Combines SQLite FTS5 full-text search with local vector embeddings. Retrieve relevant code context, architectural choices, and prior fixes in <1.2ms.

3-Layer Graph Architecture

Organizes data hierarchically into Session Frames, Memory Nodes, and Knowledge Clusters. Preserves long-term project intent across independent subagent invocations.

Desktop Shell & Bun Backend

Bundled as a standalone Bun single-file executable backend with an Electron PTY terminal shell. Instant launch with zero external Node runtime dependencies.

Command Line & Tooling

Developer & MCP Interface

Manage memory vaults, query reasoning nodes, or serve IPC endpoints directly from the command line.

# Initialize a new SQLite memory vault in the current project
$ npx openatlas init --path ./.openatlas

✓ Created database schema at ./.openatlas/vault.db
✓ Initialized FTS5 full-text table
✓ Generated project configuration opencode.json
# Query local memory vault using hybrid vector-FTS search
$ openatlas search "Electron process tree termination"

RESULT [0.99 match]: Node N-01 (Session Layer)
File: desktop/main.js
Summary: Added process tree termination via taskkill /F /T /PID on Windows on exit.
# Start the background IPC memory daemon
$ openatlas serve --port 7400 --db ./.openatlas/vault.db

✓ IPC WebSocket server running at ws://127.0.0.1:7400
✓ MCP Server ready for OpenCode, Claude Code, Cursor & VS Code

$ npx add-mcp mcp-server-git -y --all

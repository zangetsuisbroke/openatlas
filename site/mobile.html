What it does 01–04
01 the map
Graph

Every file, symbol, and dependency becomes a node. The map follows the working tree — not history. Rename a function and the graph knows before you save. Rescans run async in the background; the editor never stutters.

02 the agent
Reason

Ask questions about the code you're actually writing. The agent reads the open workspace — symbols, files, terminal output — the same live picture you see. It runs local models. Your code never leaves this process.

03 the agent
Agent

An OpenCode agent runs entirely on your machine, reading the live knowledge graph and workspace files. Ask questions, run commands, refactor code — the agent sees the same picture you do. No cloud, no API keys, no data leaves your disk.

04 the timeline
Stream

Scans, rebuilds, agent turns, shell output — every event lands in a single ordered stream. No races, no dropped frames, no "which process wrote that". The whole app is one timeline you can re-read.
